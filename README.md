# Predictive Maintenance AI 🔧

A Machine Learning web application that predicts potential machine failures using equipment sensor data.

## Features
- Machine failure prediction
- Interactive Streamlit dashboard
- Random Forest classification model
- Model evaluation metrics
- Sensor input-based predictions

## Tech Stack
- Python
- Pandas and NumPy
- Scikit-learn
- Streamlit
- Plotly
- Joblib

## Dataset
AI4I 2020 Predictive Maintenance Dataset.

## Model Performance
- Accuracy: 98.25%
- Failure Precision: 83.67%
- Failure Recall: 60.29%
- Failure F1-score: 70.09%

**Note:** These results are from the current test split. Predictions are estimates, not guarantees of machine failure.

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
